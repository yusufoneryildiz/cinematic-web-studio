# 08 · A "showcase screen" made to be filmed

**Goal:** a single page that never stops moving, so a phone video of your laptop always looks alive.
**Level:** Beginner · **In the vault:** `showcase-screen-template` (config-driven, 3 concepts included)

```
Build one full-screen page for a fictional <SECTOR> brand: top nav, left column (eyebrow, 2-line
serif title with the 2nd line italic in the accent colour, one sentence, pill CTA), a large circular
masked image on the right (radial mask fading into the background), a glass info card, slide dots,
a counter and a progress bar.
Loop every 8s: cross-fade to the next image with a slow Ken Burns zoom, replay the title's line-up
animation and the fade-ins. Add canvas particles in the accent colour (sparks / dust / bokeh).
Everything in vw; all content from a config object selected by ?c=<key>. F = fullscreen, hidden cursor.
```
