# Showcase screen template

A single full-screen page that never stops moving — made to be filmed on a laptop with a phone.
Three ready concepts: `?c=grill`, `?c=barber`, `?c=estate`.

- **New concept in 5 minutes:** copy a block in `concepts.js`, change brand, copy, colours, `particles`
  (`sparks` · `dust` · `bokeh`) and put 2-3 images in `img/`.
- **Loop length:** `?loop=6` (seconds per image).
- **Filming:** `F` = fullscreen + hidden cursor.
- Works best with images whose subject sits in the middle (the edges fade into the background).
