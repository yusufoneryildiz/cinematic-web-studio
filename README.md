# Cinematic Web Studio for Claude Code

A complete website studio that runs inside Claude Code. Open the folder, describe a business — or paste
a link to an award-winning site — and the studio's agents brief, write, design, build, generate images,
test and even turn the result into an Instagram Reel.

## What you can do with it
- **`/new-site`** — a premium site for any business from a short description (Turkish, English, any language).
- **`/rebuild <url>`** — take a site you admire and rebuild its design language and motion for your own
  brand, with original copy and images.
- **`/reel`** — turn a phone video of your laptop into a finished 1080×1920 Reel with hook text, CTA,
  music, cover and caption.
- **`/qa`** — screenshot-based visual QA at desktop and mobile before anything ships.

## What's inside
| Folder | Contents |
|---|---|
| `CLAUDE.md` | the studio's operating manual — routing, rules, stack choice |
| `.claude/agents/` | 8 specialists: creative director, reference analyst, copywriter, UI designer, motion engineer, builder, QA reviewer, performance engineer |
| `.claude/skills/` | 6 studio skills + 2 bundled design skills, with working scripts (capture, QA, reels, images) |
| `.claude/commands/` | `/new-site` `/rebuild` `/reel` `/qa` |
| `templates/` | 4 production-tested templates: Mavera (14-section cinematic one-pager), Showcase screen, Zanaat & Meraki (barber/salon, React), Koru (real estate, React) |
| `prompts/` | 10 standalone prompts for the signature effects |
| `guides/` | filming your screen, caption formula, comment → DM funnel |
| `START-HERE.html` | visual tour + the full image library |

Start with **INSTALL.md** (15 minutes), then open **START-HERE.html**.
