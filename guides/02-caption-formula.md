# The caption formula

The accounts that grow fastest in this niche write almost the same caption every time:

```
What if a <SECTOR> website felt like <UNEXPECTED THING>?

<Short line.>
<Short line.>
<Short line.>

<One sentence on why it matters to the business — first impressions, trust, price.>

Comment "<KEYWORD>" and I'll send you <the source code / a free example / the breakdown>.

#webdesign #webdesigner #websitedesign #uiux #creativewebsite #gsap #awwwards
```

Examples of the first line:
- What if a real-estate website felt like a private gallery?
- What if a barbershop website felt like a movie trailer?
- What if a coffee brand's website felt like the first sip?

Why the comment keyword works: every comment is a signal to the algorithm, and each one is a warm lead
you can reply to (see guide 03 to automate the reply).
